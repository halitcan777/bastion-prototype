# БАСТИОН — прототип сайта

Кликабельный прототип сайта сети бизнес-центров «Бастион» (Санкт-Петербург).
Направление **B «Сеть площадок»**: сначала выбираем место, потом помещение.

**Живая версия:** https://halitcan777.github.io/bastion-prototype/

Это прототип, а не боевой сайт. Данные сняты с `bastion.spb.ru` 03.09.2026.
Всё, чего у заказчика ещё нет, помечено пунктиром в `[квадратных скобках]` —
ставки, год основания, число арендаторов, высота потолков, нагрузка на пол,
метро у Менделеевской, описание Карпинского.

---

## Страницы

| Файл | Что это | Что кликается |
|---|---|---|
| `index.html` | Главная | Карта: клик по точке переключает площадку; наведение на карточку синхронизирует карту. Чипы назначения фильтруют таблицу «Свободно сейчас». Аккордеон вопросов. Форма заявки. |
| `katalog.html` | Каталог свободных площадей | Фильтры по 30 реальным помещениям: площадка, назначение, площадь, «заехать сразу», «скрыть бронь». Сортировка, список/плитка, снятие фильтра чипом, пустое состояние, сброс. |
| `ploshchadka.html` | Площадка, БЦ «Ручьи» | Четыре таба, галерея, фильтр внутри свободных площадей, переключение 12 этажей на планах. |
| `pomeshchenie.html` | Карточка помещения | Галерея, табы, избранное, «поделиться», форма записи на просмотр. |
| `kabinet.html` | Кабинет арендатора | Табы: документы, пропуска, заявки инженеру, оплата, мои помещения. Форма заявки. |
| `sistema.html` | Дизайн-система | Смена акцента: один токен перекрашивает весь сайт. |

Адаптив встроен в те же страницы — точки слома 1240 / 1000 / 680 px.
На мобильном таблицы превращаются в карточки, появляется закреплённая панель действия.

## Структура

```
assets/bastion.css   вся дизайн-система: токены, типографика, компоненты, адаптив
assets/app.js        вся интерактивность + данные (4 площадки, 30 помещений)
*.html               страницы
```

Зависимостей нет. Единственное внешнее — шрифты IBM Plex из Google Fonts.

## Два UX-решения, ради которых это сделано

1. **Витрина и обслуживание разрезаны.** На текущем сайте пункт меню
   «Арендаторам» ведёт не арендатора, а потенциального клиента. Здесь
   «Площадки» — для того, кто выбирает, «Кабинет» — для того, кто уже арендует.

2. **У каждого помещения появилось целевое действие.** Сегодня карточка
   помещения заканчивается фразой «Подробности по телефону» — ни кнопки,
   ни формы.

## Что ещё чинится по ходу

- `og:url` на текущем сайте зашит на корень — ссылка на помещение в мессенджере
  разворачивается как главная страница
- телефоны через устаревшую схему `callto:` с пробелами не кликаются
- у главного инженера Ручьёв номер набран буквами «О» вместо нулей
- «Другие объекты» — пустая страница с прочерком
- Карпинского, 38к1 — объект без описания, хотя именно там продаются 4 ГАБ

Разбор целиком — в `../01_карта_сайта_и_аудит.md`.
