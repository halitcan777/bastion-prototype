# БАСТИОН — сайт сети бизнес-центров

Прототип сайта сети бизнес-центров «Бастион» (Санкт-Петербург), направление **B «Сеть площадок»**.

**Живая версия:** https://halitcan777.github.io/bastion-prototype/

Весь контент перенесён с действующего `bastion.spb.ru` (снято 03–04.09.2026).
Фирменные цвета и логотип — оттуда же. Ничего не выдумано: там, где у сети нет
публичных данных (например, арендные ставки), блок не заполнен цифрой, а честно
отсылает к отделу аренды.

---

## Древо сайта

```
Главная
├── Площадки
│   ├── Технопарк «Литовская, 10»      о площадке · площади · планы · документы · контакты
│   ├── БЦ «Менделеевский»             о площадке · площади · документы · контакты
│   ├── БЦ «Ручьи»                     о площадке · площади · 12 планов · документы · контакты
│   └── Торговый комплекс «Карпинского, 38к1»
├── Свободные площади                  каталог 30 помещений с фильтрами
│   └── Карточка помещения
├── Продажа объектов                   5 объектов готового арендного бизнеса
│   └── Карточка объекта × 5
├── Арендаторам                        документы · пропуска · заявка инженеру · график
├── О сети                             о компании · преимущества · условия · публикации
├── Новости                            новости компании · новости недвижимости
├── Контакты                           общие · по каждой площадке
├── Политика обработки персональных данных
└── Карта сайта
```

**Ключевое решение:** витрина и обслуживание разведены. «Площадки» — для того, кто
выбирает помещение, «Арендаторам» — для того, кто уже работает в сети. На текущем
сайте пункт «Арендаторам» ведёт не арендатора, а потенциального клиента.

## Что перенесено

- Описания всех четырёх площадок с корпусами, лифтами, мощностями, транспортом
- 30 свободных помещений: код, площадь, этаж, назначение, статус
- 5 объектов на продажу с арендаторами, арендным потоком и окупаемостью
- Полные пакеты документов по каждому объекту (у Литовской — 16 приложений)
- Поэтажные планы: 5 у Литовской, 12 у Ручьёв
- Все контакты: отдел аренды, управляющие, инженеры, охрана, ресепшн, секретарь
- 14 новостей и 5 публикаций «Делового Петербурга»
- Текст «О нас», преимущества, условия аренды, политика обработки данных

## Фирменный стиль

Взят с оригинала:

| | |
|---|---|
| Мокко | `#5D4846` — основной |
| Золото | `#D7B56D` — акцент |
| Светлая охра | `#FFE9BB` |
| Заголовки | Oswald (шрифт их сайта) |
| Текст | PT Sans |
| Цифры | IBM Plex Mono |

**Логотип** снят с сайта и векторизован: растр 284×176 → трассировка → SVG.
Три готовых варианта — `assets/logo.svg` (мокко), `logo-light.svg` (белый),
`logo-gold.svg` (золото). Масштабируется без потерь.

**Фотографии.** Оригинальные снимки не переносились. Вместо них — спокойные
фирменные слоты с подписью, что за кадр туда встанет: фасад, КПП, разгрузка,
типовой офис. Так видно замысел и не тащится плохое качество.

## Структура

```
src/data.js      весь контент сайта — правится здесь
src/app.src.js   исходник интерактива
src/build.mjs    сборщик: data + шаблоны → 20 HTML-страниц
assets/          стили, скрипт, логотипы, фавиконка
*.html           собранные страницы
```

Пересборка после правки контента:

```bash
node src/build.mjs
```

Зависимостей нет. Единственное внешнее — шрифты из Google Fonts.

## Интерактив

- **Главная** — карта: клик по точке переключает площадку, наведение на карточку
  синхронизирует карту. Чипы назначения фильтруют таблицу «Свободно сейчас».
  Аккордеон вопросов, форма заявки.
- **Каталог** — фильтры по всем 30 помещениям: площадка, назначение, площадь,
  «заехать сразу», «скрыть бронь». Сортировка, список/плитка, снятие фильтра
  чипом, пустое состояние, сброс.
- **Площадка** — пять табов, галерея, таблица свободных площадей, переключение этажей.
- **Помещение** — галерея, табы, избранное, «поделиться», запись на просмотр.
- **Арендаторам** — четыре таба, вход в сервисную службу, заявка инженеру.

Адаптив встроен: точки слома 1240 / 1040 / 680 px. На телефоне таблицы
разворачиваются в карточки, снизу появляется закреплённая панель действия.
